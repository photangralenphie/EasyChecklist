# WIP - EasyChecklist
![EasyChecklist](https://github.com/user-attachments/assets/1e82213d-faa5-4e74-bca4-98a7686a09c4)

This is my attempt of creating a checklist app using the latest Apple Frameworks.
It is written in Swift 6, SwiftUI and uses SwiftData.
This is still a work in progress.

It extensivly uses Liquid Glass and MeshGrandients because I like it.

Works on iPhone, iPad and Mac through MacCatalyst (full Mac app coming in the future (hopefully)).

Requirements:
 - iOS/iPadOs/macOS 26
 - only self compiled at the moment
